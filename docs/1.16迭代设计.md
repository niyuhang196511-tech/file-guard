# FileGuard 1.16.0 · 相同内容追溯的 100 项优化与验收

在「相同内容追溯」中，可按仓库保存的 SHA-256 查找同一份正文被哪些文件、历史版本和目录复用。打开中文离线预览，点击「查看示例交接副本」，可看到「月末交接签收.txt」V1、V3 和「质检交接备存.md」V1 引用同一份正文。切换到「仅显示符合分组筛选的引用」可核查指定范围，再打开版本、与上版比较或校验对应归档副本。

## 统计范围

分组以已保存字节的完整 SHA-256 为依据。内容相似或文档视觉相同的对象，可使用既有版本对比进行人工核对。文件状态和最近登记路径来自当前索引，保存后缀与保存时间属于具体版本。正文追溯遵循版本时间线的可见范围，和公开事件的撤回各自独立。

条件应用于引用记录，再按剩余引用进行分组。归档校验会检查所选摘要在整个仓库中的长度一致性。引用或目录状态在两次刷新之间变化时，结果和导出会反映最新索引。
