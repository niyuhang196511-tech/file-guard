# FileGuard 1.23.0 · Windows 采集与扫描诊断的 100 项优化与验收

在「目录监控」选择仓库台账，打开「扫描运行记录」。筛选日期和结果，跨页选中两条记录查看指标差值，再打开「当前等待队列」核对待处理文件。桌面开发版可按相同条件导出 CSV。离线预览提供构造的等待、完成和中断场景。

## 001–010　Windows 文件采集

| 编号 | 验收项 |
|---|---|
| 001 | 路径返回创建时间、读取句柄返回变更时间时，稳定文件可以建档。 |
| 002 | 路径与句柄以卷和文件身份核对是否为同一文件。 |
| 003 | 比较路径和句柄的长度，拦截开读前的截断与增长。 |
| 004 | 比较路径和句柄的修改时间，拦截开读前的写入。 |
| 005 | 同一读取句柄的前后检查使用完整纳秒时间签名。 |
| 006 | 采集再次核对路径，识别读取结束后发生的同名替换。 |
| 007 | 读出字节数与登记长度一致时才继续发布快照。 |
| 008 | 完整保存核对复用路径与句柄的身份判断，能核对正常保存的 Windows 文件。 |
| 009 | 文件在完整保存核对期间变化时，提示用户重新核对。 |
| 010 | 只改变文件名大小写的重命名沿用同一文件身份和历史版本。 |
