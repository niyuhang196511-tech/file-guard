# FileGuard 1.13.0 · 100 项优化与验收清单

本轮适用于现有 1.12 仓库升级以及新仓库。想先试效果，可以打开离线预览并搜索“退货轨迹.csv”，在历史版本中选择“字段变动轨迹”，输入 RK-001。示例会显示同一编号的数量从 100 改为 120，再回到 100。

下表按可观察行为计数，每行含操作与预期结果。同一项通常与其他项共享一个实现或测试用例；100 项验收点与自动测试数量分别统计。涉及数据损坏或记录撤回时，请使用测试仓库。

## 适用范围与验证

期间对照采用事件保存时记录的本地日期与小时。本期与上期的总数都按基础筛选计算，趋势和排序作用于下方分组表。时间窗口最长 366 天。字段轨迹读取所选文件可见相邻版本的已解析差异；没有保存或尚未解析的中间状态无法推断。“回到先前可见值”的判断限于所选区间和同一记录、字段或位置。按编号跟踪取决于解析器是否识别出可靠的编号列。

VCF 和 ICS 比较存储的组件、属性和参数，保留原始属性值；日历规则不展开为未来发生时间。GeoJSON 比较坐标数组与属性，不进行坐标系变换。WAV 支持 RIFF/WAVE；本轮为 PCM 和 IEEE 浮点格式计算帧数与时长。TAR 支持未压缩归档，正文使用摘要比较。原文件夹在后台产生新版本后，刷新查询即可复核新的可见范围。

测试包括后端数据库和真实文件、可单独运行的引擎协议，以及 Vue 中文界面交互。Windows 托盘关窗、WebView2 和 Office 占用场景需在 Windows 实机验收。
