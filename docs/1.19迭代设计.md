# FileGuard 1.19.0 · 历史版本交付篮的 100 项优化与验收

在「历史版本」将指定副本加入交付篮，继续到其他文件和目录选择所需版本，再打开「历史版本交付篮」检查成员、导出 CSV 或生成 ZIP。接收方可用「系统设置 → 核查交付包」校验包内副本。有原交付篮的人员可按所选版本核对漏交、多交和错版。

离线预览提供预先生成的三版本 ZIP，包含退货台账的 V1、V3 和另一目录的作业指导书。其他离线选择支持查看清单和导出 CSV。

## 核查口径

包内核查用于检查文件是否符合随包清单。按原选择核查还会比较成员路径、版本号、字节和 SHA-256。交付包不带发送者签名。登记文件名来自仓库当前索引，包内路径由版本 ID 和历史后缀确定。在其他仓库只需做包内核查；按篮核查使用创建包时的源仓库版本选择。
