# FileGuard 1.11.0 开发版 · 100 项优化与验收清单

在 1.10.0 的基础上修改。打开离线中文预览，可在“差异检索”中输入“库存台账”，选择“数值下降”，然后从结果回到对应版本和单元格位置。

搜索范围为普通日志中可见、由引擎成功解析的相邻版本事件。工作簿整表查找还可搜索当前两份快照中的相同单元格。原始版本、备份和管理审计继续遵循各自的访问范围。

## 验证与运行边界

后端使用 Linux、Python 3.12、SQLite 和生成的真实文件回归。160 个后端用例中 158 个通过，2 个 Windows 专属用例跳过。界面通过实际 Vue 模板与交互方法验证，覆盖 11 个页面。独立引擎进程检查覆盖建档、解析、检索、定位、恢复和退出。

工作表检索只读已有值和公式表达式。解析器不会启动 Excel 重新计算公式。宏、邮件 HTML 和电子书资源均作为数据读取。GPX 点以在轨迹段内的位置配对。

稳定等待用于监听到的写入和随后复查；手工编辑器内尚未落盘的文字无法采集。两次稳定采集之间被覆盖的中间状态可能合并。

Windows 程序的主窗口关闭到托盘后由独立引擎工作。安装包构建、WebView2 显示和关窗后的真实编辑器行为需在 Windows x64 验收。源码含构建命令及交互式冒烟脚本，本次交付无 Windows 二进制。
