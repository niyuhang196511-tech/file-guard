本轮基线为 1.7.0。每项列出可以观察到的行为。同一功能涉及界面、引擎和离线预览时合并计数。

## 文件开着时如何记录

未保存的编辑保留在编辑器内存。手动保存或自动保存写入受监控路径后，引擎可读取稳定状态。若应用独占文件，目录卡会显示等待项并安排复查。快速连续保存、长期占用或写入过程中停顿，都会影响可观察到的中间版本。引擎无法判断业务上的“已经改完”。需要恢复原文件时，宜先保存并关闭编辑窗口，避免编辑器之后用旧内容覆盖恢复结果。

## 验证范围

自动化回归使用临时目录、真实 Office/图像/文本文件和独立 SQLite 仓库。可运行 tests/test_iteration18.py 对应的 unittest 测试、tests/test-view.cjs 和 scripts/check-engine.py。完整命令见 README。

本轮执行平台为 Linux。文件被占用场景采用模拟拒绝读取，并验证同目录其他文件继续入库。扩展 Windows 共享读句柄及恢复独占锁各有一个 Windows 专属测试，本轮均跳过。Microsoft Excel、WPS、Windows WebView2 与安装包仍需在 Windows 验证。图像比较显示属性和首帧摘要，PDF 使用可提取文字及对象，扫描件无 OCR。
