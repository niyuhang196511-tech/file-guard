# 操作与维护

## 开始记录

打开目录监控并选择「添加目录」。桌面版可用「浏览」选择已有文件夹。排除规则支持中英文逗号、中英文分号、顿号及换行，可匹配名称或相对路径，例如 `*.tmp, 缓存, 草稿/*`。默认跳过 Office 临时锁文件、符号链接和重解析点。单文件大小上限以 MiB 填写，0 表示不限制快照大小。暂停或移除监控任务均保留已存历史。编辑已暂停目录的排除规则或大小上限后，目录保持暂停。

第一次扫描显示「初始建档」，建立文件 V1。首次完整扫描后创建的新文件显示「新增」。时间戳或文件标识变化而内容摘要相同记为「属性修改」。同一监控根内，文件标识与内容都可唯一对应时识别重命名或移动。跨根移动、同时改名改内容等无法确认身份的场景可能显示新增和删除。

## 文件保持打开时

Excel 或 Word 打开后可以继续编辑。Ctrl+S 或自动保存将内容写入本机监控目录后才可能形成新版本。Office 写入通知先进入稳定性观察；扫描中内容变化或遇到占用，将保留旧版本并安排复查。「等待保存」列出文件和复查原因。快速连续写入可能合并为一个版本。长期独占期间请勿依赖本系统找回尚未落盘的内容。

## 查找与比较

- **系统总览**显示当前文件数、当日业务变更、累计版本和待处理任务。趋势可切换 7、14、30 日。历史版本统计包含已删除文件。今日变更和趋势均排除首次建档。
- **目录监控**支持按完整路径、目录名或状态筛选。卡片可扫描此目录、进入该目录的变更记录，或搜索子目录并查看含后代的文件数量。「上次完成扫描跳过」可展开查看原因，跳过整棵目录按一项计。修改规则后可主动扫描，离线期间保留最近一次完成扫描的结果。点击通知中心的目录错误，可直接定位到对应目录。
- **文件管理**默认列出当前监控范围，按最近变化倒序。范围可切换为全部历史、已删除、规则已排除或目录已移除。搜索旧文件名或移动前的相对路径会显示匹配的原路径。同一路径删除后重建的文件保留两条独立记录。可以按文件名、路径、后缀或目录筛选。Windows 桌面版的「打开位置」进入所在文件夹。
- **变更记录**可按现路径或原路径、日期范围、目录、扩展名和变化类型组合查询。「今天」「近七天」按本地日期筛选，可勾选「隐藏初始建档」。从详情点击「返回变更记录」可回到原筛选和页码。表头右上方可导出全部匹配记录，生成可用 Excel 打开的 UTF-8 BOM CSV。初始建档和单纯删除会显示其事件信息。
- **历史版本**按每页 10 条展示版本号、保存时间、大小、解析状态和 SHA-256。可输入 V2 或 2 精确查找第二版，并按保存日期缩小范围。全局搜索（Ctrl K）也会搜索已删除文件及已移除目录中的历史文件。
- **版本对比**可选择同一文件的任意两个版本，按工作表、段落分组或位置关键词筛选。旧值与新值并列展示。「文件大小与 SHA-256」可核对二进制差异。
- **审计中心**显示应用内发生的目录操作、设置变更、导出和恢复。文件事件保留采集来源，真实编辑人需要独立可靠证据。
- **通知与设置**展示目录错误和解析失败计数，可重试失败解析、切换主题、配置校对周期、校验仓库和创建备份。

版本对比的关键词可匹配工作表、位置、记录编号、旧值和新值。点击「导出筛选结果」可导出全部匹配项。CSV 以 UTF-8 BOM 编码，包含文件、旧／新版本号、分组、位置、编号、变化类型与前后值。公式作为文本保留。示例预览在浏览器下载 CSV，桌面版保存到选择的新文件名。

## 格式与定位粒度

| 格式 | 当前解析能力 |
|---|---|
| xlsx / xlsm / xltx | 单元格内容与类型、公式、批注、主要格式、合并区域、显式行列属性、数据验证、表格定义和工作表顺序。工作表改名按两组位置变化展示。 |
| docx | 正文及明确设置的分节页眉、页脚段落和样式，表格、嵌套表格、媒体及嵌入对象摘要。 |
| pptx | 页序、页标识、文本、表格、形状结构及媒体摘要。 |
| PDF | 页数变化、按页文本、页面内容流与图像摘要、元数据。无 OCR；受密码保护文件保留快照和错误原因。 |
| CSV、TSV、JSON、YAML、XML | 行列、字段路径、节点及属性。文本尝试 UTF-8、带 BOM 的 UTF-16 和 GB18030。 |
| TXT、Markdown、SQL 及常见代码文本 | 行级文字差异，分别显示两侧行号。 |
| 旧格式 xls / doc / ppt，图片、视频及其他二进制 | 可读且未被规则跳过的普通文件均保存大小、摘要及原始版本。 |

解析针对已保存的快照。单文件解析上限为 32 MiB，Office 解包检查上限 128 MiB，结构位置上限 25 万。达到上限后保留版本并显示解析原因。公式对比读取公式表达式，程序不会运行宏或重算公式。首行为表头、编号唯一且连续的台账支持按编号对齐。原编号顺序须保留，且此次编号集合仅增加或仅减少；重复编号、混合删增、排序变化、存在空行或多列候选编号时使用坐标对比。字段名清晰且唯一时，按列名对齐，单独记录列顺序、字段增删及对应记录值。列布局稳定时可合并纯行位移导致的相对公式平移。列布局变化时保留公式文本的修改。按差异类别或字段名可定位业务变化；Excel CSV 另含字段、类别和两侧类型。点击「交换版本」可反向复核，点击「清除筛选」恢复全部结果。Word 默认将相同段落作为前后版本的定位依据；内容被重排、重复或大范围重写时，可切换「按原始位置」复查。长段落保留完整前后值，局部文字高亮用于较短的修改段落。表格仍按表号与单元格位置比较。

## 恢复或另存

「另存」导出所选版本到新文件名。如果目标已存在，选择其他名称。「恢复」会显示文件和来源版本号，确认后校验历史对象，保存尚未记录的当前内容，再写回并验证 SHA-256。成功后生成新版本及管理日志。恢复确认框显示完整路径、来源版本、大小与当前存在状态。被删除的文件已有同名替代文件时，请另存历史副本；即使替代文件尚未被扫描，执行时也会检查。请关闭正在编辑的文件后再恢复。

审计中心的「从」「至」均包含所选日期，可和操作类型、名称或内容关键词组合。

恢复过程使用持久意向记录。意外退出后，启动校对会检查目标文件和意向状态，并记录核对结果。文件暂不可读时只延后该项核对，其他任务继续；在系统设置中可查看待核对数量并重试。写回前后摘要相同且发生中断时，仅记录可核实的内容一致，避免生成未经确认的成功版本。恢复时请保持磁盘有足够空间。

## 存储、备份与离线还原

安装版数据默认位于 `%LOCALAPPDATA%\FileGuard\Data`，便携版位于程序旁的 Data 目录。SQLite 保存索引、事件和差异，objects 保存按摘要分桶的历史原件。不要手工删除其中任一部分。

生成正文差异前会核对两份原件的长度及 SHA-256。升级后，已有正文差异会在后台重新校验和解析，完成后即可在差异检索和字段轨迹中查询。重新采集到同一份正确内容时，可以修复对应的损坏对象。拿到正确原件后，可在历史版本或系统设置重试失败解析。

在系统设置创建 ZIP 备份，选择仓库和监控根目录以外的新文件名。备份读取 SQLite 快照并校验引用的每个对象。还原时先从托盘「退出监控」，再在程序目录执行：

```powershell
.\fileguard-engine.exe --restore-backup "D:\备份\文件监控.zip"
```

源码运行时用 `python -m engine.main --restore-backup "D:\备份\文件监控.zip"`。工具检查工作区占用、数据库版本、外键和所有历史对象摘要，再切换数据目录。已有仓库保留在同级「Data-还原前-时间」目录。跨机恢复后检查目录路径；无法访问的根目录会显示异常。

## 运行、升级与卸载

桌面窗口的关闭按钮隐藏工作台。通过托盘菜单再次打开，或选择退出监控。希望重启后自动恢复监控时，在系统设置启用「登录 Windows 后后台启动」。监控按用户登录会话运行。

监控引擎启动失败时，工作台会显示原因并在后台重试。便携版缺少 `fileguard-engine.exe` 时，将同一构建的引擎文件补回程序目录即可。可以在工作台点击「重试连接」查看最新状态。

当前数据库版本为 11。首次运行自动建表，升级保留历史原件、版本编号和事件。发现更新版本的数据格式会停止打开。升级前创建备份并退出监控，安装同一产品标识的新版后复核文件数与历史。降级请用升级前的备份。便携版升级复制新程序文件时保留原有 Data 和 portable.flag。卸载前关闭登录启动并备份。未签名构建的发布与推广、长期压力测试、净机升级测试均需在目标环境完成。



## 记录管理与后台监控

仓库负责人运行 FileGuard-RecordAdmin.cmd 设置管理口令。在变更记录行末选择「管理记录」处理更正、撤回或恢复。撤回的公开行可通过变更类型「已撤回」找到。管理口令按次输入，核查结果在界面隐藏或停留约一分钟后清除。设置口令之后，从应用创建完整备份也要验证口令。仓库数据库和历史备份的文件权限由部署方管理。

Windows 桌面版关闭主窗口后，可从系统托盘唤回。退出监控需从托盘菜单执行。建议在工作用 Windows 设备接入日常文档前，按 README 的隔离验收流程验证本机的关窗、重启引擎和单实例唤回。
