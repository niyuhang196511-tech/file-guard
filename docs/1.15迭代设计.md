# FileGuard 1.15.0 · 历史正文检索的 100 项优化与验收

在「历史正文检索」中输入记得的词句，以行号和上下文找回已保存的文本版本。离线预览可点击「查找示例 RK-001」，查看「退货轨迹.csv」的不同保存版本。点击「打开命中版本」可核对时间线，点击「与上版比较」可复查当次修改。

下表逐项记录已实现的行为和复查方式。相关入口为浏览器开发版、Windows 桌面版和离线样例。

## 001–010　入口与工作流

| 编号 | 改进 | 验收方式 |
|---|---|---|
| 001 | 左侧导航增加「历史正文检索」 | 从监控工作台直接打开。 |
| 002 | 从目录卡片进入 | 点击「检索目录正文」后打开检索页。 |
| 003 | 自动带入目录范围 | 使用目录入口后，监控目录选择器显示对应目录。 |
| 004 | 从文件历史进入 | 在「历史版本」点击「检索本文件正文」。 |
| 005 | 从版本对比进入 | 在已有文件的「版本对比」使用同一入口。 |
| 006 | 通过文件身份限定范围 | 同名文件有多个身份时，只搜从入口选中的那个文件。 |
| 007 | 单文件入口默认搜所有历史版本 | 在较早版本中保存关键词，打开该文件的正文检索即可找到。 |
| 008 | 显示单文件限定 | 路径标签显示当前限定的文件。 |
| 009 | 单独取消文件限定 | 点击取消限定，保留已填的关键词和目录条件。 |
| 010 | 清空条件并清除结果 | 点击「清空条件」恢复默认范围，同时清除批次、命中和错误提示。 |

## 适用范围

正文检索按历史快照的物理行进行。二进制 Office、PDF、图片和压缩包仍使用各自的历史版本及差异入口。界面显示文件最近登记的路径。公开事件的撤回与快照保留沿用现有规则，历史正文检索所见与版本时间线的可见范围一致。

一次检索固定纳入的版本 ID 上限。各批次按当时的文件状态和关注标记筛选。桌面版导出时按已提交的条件重读当前批次，如果期间文件状态或副本可用性改变，导出结果也可能变化。离线预览使用随附的虚构业务数据。

独立引擎协议用 `scripts/check-engine.py` 验证。Python 新用例覆盖编码、命中定位、游标、大小预算、历史文件、对象完整性和 CSV。离线交互用 `tests/test-view.cjs` 验证。
