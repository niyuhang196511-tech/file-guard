# FileGuard 1.14.0 · 100 项优化与验收清单

本轮针对两个日常问题：保持文件打开时，如何知道磁盘上的这一版是否已记入历史；两份台账的列名、顺序或文件格式不同时，如何确认同一批物料到底改了什么。以下每项都对应实际入口与可复查的结果。

**离线演练**：在文件管理中搜索「计划领料.xlsx」，打开历史版本里的「台账对账」，左侧选 V2，在右侧搜索并选择「领料回执.tsv」的 V2。以物料编号和批号为组合键，关闭“区分文本与数值类型”，开启十进制比较后重新对账。A-01 / L1 可看到计划 80、实发 78，同编号的 L2 独立显示。另在回执的历史版本里打开“保存核对”，切换完整核对，查看示例现场已保存但尚未入库的改动。

| 编号 | 改进 | 操作与预期结果 |

| 002 | 防止把等长文件误报为已保存 | 等长改写内容，快速模式明确显示“大小相同，尚未核对内容”。 |

| 004 | 识别尚未采集的磁盘改动 | 将文件保存为新内容、暂不扫描，完整核对显示“磁盘内容尚未入库”，核对本身不新增版本。 |

| 009 | 保持编辑器打开时核对 | 用已打开的读写句柄保存后执行完整核对，能发现已落盘的新内容，内存中的草稿不产生结果。 |

| 012 | 区别文件缺失与整个目录离线 | 分别删除单个文件、断开测试监控目录，查看不同的原因。 |
| 013 | 区分旧文件与同名新文件 | 已删除文件的历史路径重新出现时，区分尚未确认身份和已被另一在册文件占用两种情况。 |
| 014 | 避免从链接或特殊文件读取正文 | 将原路径替换为链接或目录后核对，分别提示跳过链接或路径并非普通文件。 |
| 015 | 说明占用或无权限状态 | 读取被拒绝时显示“文件被占用或无读取权限”，可以保留当前编辑会话并稍后重查。 |
| 016 | 解释当前采集范围 | 同时查看目录启停、文件在册范围和按当前路径、大小计算出的排除规则结果。 |
| 017 | 显示等待原因和进度 | 对正在等待的文件查看首次、最近等待时间和尝试次数，以及目录配置的稳定等待时长。 |
| 018 | 显示目录扫描状态 | 查看最近一次目录扫描、现有扫描错误和待执行扫描的来源。 |
| 019 | 在编辑期间自动轻量刷新 | 桌面或本地开发版可每五秒快速核对；切换为全文或副本校验时停止周期读取。 |
| 020 | 从文件发起目录重扫 | 在启用目录中直接请求后台扫描，再次核对查看新版本。暂停或移除的目录无法从此入口排队。 |

## 适用范围

保存核对针对已建档文件。完整核对比较磁盘与版本索引，历史副本可单独校验。扫描仍遵循原有采集时机及稳定等待规则。离线预览使用真实测试文件生成的固定现场，不会访问使用者的磁盘。

对账支持 XLSX、XLSM、XLTX、XLTM、CSV 和 TSV。表格输入有单版本 32 MiB、工作簿展开后 128 MiB、单表 2 万行、256 列、30 万个行内位置及 3 MiB 文本的上限。对账与体检单次最多比较 45 万个字段位置。CSV 导出有 24 MiB 的序列化预算，超过时可缩小结果范围。各表的行号按解析后的逻辑行计算，引号内换行仍属于同一条 CSV 记录。

精确十进制比较用于至多 128 字符、显式指数绝对值不超过 200 的十进制输入，保留 CSV 原始文本精度。工作簿使用其实际存储的数值。数字阈值不应用于公式，也不推算公式结果。对账与体检只读历史版本；本地模板在仓库中保存，离线样例模板仅在当前预览会话内生效。
