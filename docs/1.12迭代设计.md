# FileGuard 1.12.0 · 100 项优化与验收清单

本轮覆盖历史版本恢复、清单交付、仓库与备份核查，以及 Excel、CSV 和 TSV 的数值差异。每项给出操作和预期结果。涉及损坏数据、删除文件或权限的验收，请使用临时测试目录与测试仓库。

离线中文预览可体验基于真实测试文件生成的样例。筛选范围打包、运行现场体检、实际写回恢复和核查自选 ZIP 请使用桌面开发版。交付包内的摘要用于检查内容一致性；核实是否为自己选定的版本，请在相应历史清单中发起对账。

| 编号 | 改动 | 验收方法与预期结果 |
|---|---|---|
| 001 | 并排核对摘要 | 选择同样大小、内容不同的两个版本，预览显示现场与所选版本各自的 SHA-256。 |
| 002 | 并排核对大小 | 选择长短不同的版本，预览分别显示当前文件与历史副本的字节量。 |
| 003 | 标出覆盖方向 | 以较短版本恢复较长文件，写回字节差为负数。 |
| 004 | 显示最新在册版本 | 从第三版回看第一版，预览同时指出选择 V1、最新 V3。 |
| 005 | 提示现场存在未采集修改 | 暂停扫描、保存新内容，再打开预览，界面提示恢复前需要保留现场。 |
| 006 | 区分路径尚未存在 | 删除文件后预览历史版本，现场一栏显示路径不存在。 |
| 007 | 拦截失真的历史对象 | 在测试仓库改变历史对象的长度或内容，预览和另存都应拒绝。 |
| 008 | 发现生成预览时的写入竞争 | 在现场文件读取期间再次修改文件，旧读数不能用于确认恢复。 |
| 009 | 防止确认旧预览覆盖新保存 | 打开预览后保存新内容，按原确认恢复时要求重新预览。 |
| 010 | 把确认绑定到具体版本与路径 | 将同一预览凭据用于另一版本，或在重新扫描改名后再确认，写回被拒绝。 |
| 011 | 文件重新出现时重新确认 | 对缺失路径做预览，再创建同名文件，检查新内容未被覆盖。 |
| 012 | 相同内容免写回 | 预览与在册内容相同的当前版本，界面不提供写回，受保护的重复请求不增加版本。 |
| 013 | 历史另存完整后才发布 | 模拟复制中断或目的地同时出现，已有文件保持原样，没有可误用的半份历史副本。 |

## 验证范围

Linux 后端以临时 SQLite 仓库、真实文件和受控故障运行集成回归。界面另以同一份 Vue 模板核对 11 个页面，独立引擎进程验证交付包、现场核对与预览后恢复等命令。100 项是逐项验收口径，自动测试数单独统计。

文件可以保持打开。保存或自动保存并落盘、稳定可读后才有可采集的版本；只在编辑器内存里的内容无法记录。原位恢复前请先保存并关闭对应编辑器，避免后续自动保存覆盖恢复结果。Windows 原生托盘、Office 独占句柄、安装包构建与 WebView2 界面仍待 Windows 实机验收。
