# 1.3.0 迭代设计

本次以质量部的《检验作业指导书》为样例。复核时需要区分新增条款、真正修改的文字和文件版次，不希望插段引起后续数十段被误报。

1. Word 默认用内容相同的段落定位前后关系，分别标注旧／新段号，保留原始位置视图。段落内部的短文本修改在两栏高亮，导出保留完整前后原文。
2. 对正文、明确设置的分节页眉和页脚分别比较；读取其表格及嵌套表格。沿用上一节的页眉页脚仅记录定义处。Word 快照按新规则后台重新解析。
3. 审计列表同时匹配操作名称与内容，增加操作类型、起止日期筛选，汇总总数与分页保持一致。
4. 中断恢复任务逐条核对。一条记录暂时读不到时保留待办，继续其余任务。遇到另一文件占用原路径时记录冲突。通知和系统设置显示待核对数，并提供手动重试。
