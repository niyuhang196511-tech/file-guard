## 实现范围与已知边界

本版监控稳定、可读取且符合规则的保存状态。暂停、断电或快速连续写入期间消失的中间状态无法补建。网络路径的文件标识和通知行为取决于文件系统；无法唯一判断的移动会分拆记录。Excel 台账可按唯一编号和明确的字段名对齐，显式行列属性按坐标比较；Word 正文和页眉页脚支持按段落内容及原始位置比较；重复条款、段落重排及大范围重写可能需要人工核对。复杂域、扫描件 OCR、精确推断工作表重命名、像素级比较、加密存储、操作人归属与多用户权限角色属于后续扩展。访问控制沿用当前 Windows 用户与文件系统权限。

实现选用了 Vue 3、TypeScript、Tauri 2、Python 和 SQLite；图表由本地 SVG 和 CSS 绘制。Windows 当前发布门槛为安装包编译、净机验收和实际文件锁／托盘测试完成。
