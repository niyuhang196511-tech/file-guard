# 1.2.0 迭代设计

- 监控任务按目录合并。首次通知设定扫描时刻，同一批后续通知不能推迟它；手动与周期全量校对保留优先级。编辑规则保留暂停状态，重新接入已移除的目录才启用监控。
- 同大小文件若仅变更时间或改名，核实摘要后复用已有原件。全量校对继续检查同大小、同时间的实际内容变化。
- 恢复前展示当前目标、来源版本和大小。已删除文件的原路径被新文件占用时提示另存；执行恢复时再次检查目标。
- 差异查询覆盖工作表、位置、编号、旧值、新值。相同版本和模式重复查询复用明细，连续翻页复用筛选结果。界面展示可直接核对的版本号和匹配数。
- 导出当前筛选下所有差异。CSV 包含文件、版本、位置、变化类型和前后值；用 Excel 打开时公式按文本保留。桌面版保留导出审计，预览仅导出样例。
