# FileGuard 1.10.0 开发版 · 100 项优化与验收清单

从 1.9.0 升级。每行列出本次增量及可观察的验收结果。真实文件、SQLite、独立引擎进程和离线 Vue 工作台已在 Linux 验证。涉及 Windows 托盘、登录启动和原生进程恢复的项目须在 Windows x64 验收。

## 变更记录与隐私

| 编号 | 优化 | 验收方法或结果 |
|---:|---|---|
| 01 | 增加“移出普通日志”处置 | 在变更记录中输入管理口令并填写原因，可以将单条事件移出普通视图。原有“撤回”仍可保留公开标记。 |
| 02 | 普通查询排除已移出的事件 | 使用原事件编号或文件名检索，结果中没有被移出的那一条。 |
| 03 | 首页最近活动同步处理移出事件 | 移出当前第一条活动，刷新后由后续可见活动补位。 |
| 04 | 今日计数与趋势按可见事件统计 | 移出当天唯一的内容修改后，当天修改计数归零。 |
| 05 | 事件导出使用同一可见范围 | 指定已移出的事件编号导出，文件只含表头。 |
| 06 | 管理员可检索已移出记录 | “管理已移出记录”入口通过引擎验证口令，口令错误时无法读取。 |
| 07 | 管理目录按需展示信息 | 首次读取仅有编号、处置时间、修订号与状态。查看原始内容或恢复需再次验证。 |
| 08 | 管理目录支持按编号向后翻页 | 每批最多 25 条，使用上一批末尾编号读取更早的记录。 |
| 09 | 管理目录限制敏感信息停留时间 | 读取后清空输入框，闲置约一分钟自动关闭当前目录弹窗。 |
| 10 | 事件可按精确编号定位 | 输入事件编号只返回这一条可见记录。 |
| 11 | 公开更正说明可单独搜索 | 输入备注片段可找到已更正事件，私有处置原因未参与搜索。 |
| 12 | 增加“仅已处置”筛选 | 可将普通事件与已有修订的公开事件区分，恢复后可以继续按修订状态查找。 |

此处的隐私范围是应用的普通事件列表、事件统计及事件 CSV。管理审计保留处置动作；独立文件清单、历史版本和备份可以反映文件实际内容。能够直接读取仓库文件的人员也可能接触底层数据。已有口令沿用，首次配置使用源码包内的 FileGuard-RecordAdmin.cmd。

| 编号 | 优化 | 验收方法或结果 |
|---:|---|---|

| 15 | 识别不属于相对路径的输入 | 盘符、绝对路径和向上跳转会提示修正。 |
| 16 | 接受 Windows 反斜杠输入 | 输入带反斜杠的相对路径，可与规范化后的规则匹配。 |
| 17 | 给出实际命中的排除规则 | 对照输出中的规则文字，能够发现范围过宽的通配符。 |
| 18 | 给出被剪枝的祖先目录 | 预演“草稿/内部/文件”时，能指出阻止向下枚举的目录。 |
| 19 | 单独标明编辑器临时文件 | 测试 Office 所有者文件、LibreOffice 锁文件及 FileGuard 临时文件可见对应原因。 |
| 20 | 支持带假设大小预演 | 输入字节数，按 MiB 换算上限；等于上限允许，超出则跳过。 |
| 21 | 区分未知大小和确定允许 | 配置了大小上限但未填测试字节数时，结果提示待核对大小。 |
| 22 | 输入改变后隐藏旧预演 | 调整路径、规则、字节数或上限后，旧判定立即失效。 |
| 23 | 记录每个目录的规则沿革 | 展开“规则沿革”，按时间查看最近 100 次规则与大小上限组合。 |
| 24 | 等价配置不重复登记 | 对已归一化为同一组规则的配置重复保存，不增加沿革。 |
| 25 | 旧仓库升级时建立当前规则基线 | 1.9 仓库首次升级后可查看当时有效的规则，重复启动不会生成第二份基线。 |
| 26 | 预演与生产扫描共用文件名匹配实现 | 用同一批规则测试路径，再实际扫描目录，核对排除文件和保留文件。 |

预演只评估输入的路径和大小。读权限、链接、离线状态和实际写入由扫描时检查。设置排除规则影响后续采集；已保存的版本仍按既有保留方式管理。

## 验证范围

- 后端回归入口为 `python -m unittest discover -s tests -v`。本轮运行 142 个用例，140 个通过，2 个 Windows 专属用例跳过。新增用例位于 `tests/test_iteration110.py`，使用临时真实文件、SQLite、子进程和真实 Excel 工作簿。
- 离线交互回归入口为 `node tests/test-view.cjs docs/中文界面预览.html`，覆盖十个页面。预览可用虚构数据体验移出及恢复、目录清单交接、Excel 行筛选和 TOML 双模式。
- Windows 交互验收入口为 `python scripts/check-windows-background.py 已解压的便携版目录`。请在独立测试会话运行；脚本只终止自己启动的测试引擎进程树。安装包与现场托盘行为仍待 Windows 构建和实机验证。
