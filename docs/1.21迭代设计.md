# FileGuard 1.21.0 · 清单三方对照的 100 项优化与验收

从「目录清单」打开「清单三方对照」，选择同一目录的基准、左侧和右侧三份清单。左右两侧分别与基准比较，界面列出每个文件身份的三方结果，以及需要复核的路径争用。离线预览中，仓库台账目录有月初、月中和月末三份样例。搜索「退货轨迹」可看到月中正文变动、月末回到基准内容的结果。

## 适用范围

三方对照用于同一仓库、同一监控目录的三个已保存结果。候选来自目录路径和历史正文摘要，用于人工核对。路径争用只在能够确定候选路径的身份间计算。相同摘要可以对应不同版本号。对照读取已保存的清单和版本索引，现场文件由使用者通过原有流程管理。
