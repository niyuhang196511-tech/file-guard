# FileGuard 1.22.0 · 历史原件预览的 100 项优化与验收

从「历史版本」「版本对比」或「历史正文检索」打开指定保存，查看校验后的归档原件。文本模式按物理行展示，字节模式同时给出十六进制和 ASCII。离线预览可打开退货台账文本样例，也可查看一份历史工作簿的 ZIP 文件头。

## 适用范围

正文预览按物理行读取。CSV 中含引号的多行字段会保持原件的物理行顺序。对需要权威字节内容的场景，可使用十六进制查看或另存原件。文本 CSV 保留完整匹配行及行尾类型，适合核对和定位。离线样例包含选定文本和一个工作簿版本，实际开发和桌面模式直接读取所选仓库快照。
