# 1.1 迭代设计 · 2026-11-21

库管复核台账时，插入物料后仍需看清哪些库存数真正改过。对比页提供「按编号对齐」和「按原始坐标」两种视图，支持点击新增、修改、删除筛选。所有结果均来自已保存的两个版本。

- 自动对齐仅用于带唯一编号表头的连续数据区。保留原有编号顺序、只增加或只减少编号时，可将新增／删除记录折叠成一行，同时保留该行各字段。已匹配记录的真实变更显示前后坐标。
- 编号有重复、空缺、重排或可用编号列不唯一时，保留坐标级比较。原始坐标视图始终可选。文件快照与历史版本号维持原值。
- 格式变动在差异表展示变动属性及前后值。公式随同行平移时，可在原始坐标视图逐字核对。
- 老版本产生的 Excel 差异通过持久解析队列更新，旧仓库继续可读。离线样例和桌面应用使用同一套比较结果。
- 发布验证覆盖多表、倒序比较、重复编号、格式变化、旧库重开、筛选分页和打包后引擎运行。便携压缩包只从全新暂存目录收集程序文件。
