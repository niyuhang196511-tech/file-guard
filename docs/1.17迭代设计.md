# FileGuard 1.17.0 · 逐行来源的 100 项优化与验收

「逐行来源」以选中的历史文本为目标，向前沿相邻保存版本匹配物理行。结果给出目标行号、来源版本和该版行号。离线预览可点击「查看示例退货台账」。V3 的表头从 V1 保留，数量所在的第二行曾在 V2 变化，V3 改回旧值时被识别为 V3 的一次新出现。

## 判断口径

逐行来源表示系统根据相邻已保存文本推定的来源。正文相同的重复行按有序对齐处理。启用唯一文本移位会把未被有序对齐匹配、两侧都唯一且完全等值的非空白文本视为同一行的移位。并列的对齐方案和真正的编辑动作有可能不同，结果无法提供作者信息。

不同编码和换行方式可承接已有文本来源。逐行来源用于纯文本，二进制 Office、PDF、图片和压缩包可继续使用原有版本对比。相邻链范围内的文件登记路径为当前最近登记路径。公开事件的更正与撤回沿用既有记录规则，逐行来源采用版本时间线的可见范围。
